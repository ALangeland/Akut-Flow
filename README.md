# Akut-Flow

Arbejdsværktøjer til Alb Akut- og Traumecenter i tre udgaver: web, mobil og lokal fil til PC.

**[Åbn Akut-Flow](https://alangeland.github.io/Akut-Flow/)** · **[Mobil](https://alangeland.github.io/Akut-Flow/mobil/)**

## Udgaver

| Udgave | Hvor | Til |
|---|---|---|
| **Web** | `index.html`, `journalflow.html`, `fordelingshatten.html` | Åbnes direkte i browseren via GitHub Pages. |
| **Mobil** | `mobil/` | Installeres på telefonen og virker offline. Journalflow kan sende kladden på mail. |
| **Lokal** | `lokal/Journalflow-lokal.html`, `lokal/Fordelingshatten-lokal.html` | Hentes og åbnes som fil i Edge/Chrome på PC'en. Kun den lokale Journalflow kan indlæse kladder fra mail (📥 Indlæs fra mail). |

## Værktøjer

- **Journalflow** (tidligere Pasteplaner): journalkladde som klikjournalen med fraser, normalfund og planer, der fordeles i journalfelterne.
- **Fordelingshatten:** optælling pr. speciale i ASA-zonerne og jævn fordeling af nye akutte.
- **Fieldnotes:** kommer i næste version.

## Opdatering

- **Web og mobil** opdateres automatisk, når der er pushet en ny version. Mobilappen henter den næste gang, den åbnes med net.
- **Lokal:** hent filen igen fra startsiden eller fra mappen `lokal/` (Raw → Gem som). Planer, normalfund og kladde ligger i browseren og bliver liggende.

## Installér på telefonen

Åbn mobil-linket:

- **iPhone (Safari):** Del → **Føj til hjemmeskærm**.
- **Android (Chrome):** **⇩ Installér**, eller ⋮ → **Installer app**.

## Mail fra mobil til lokal

1. På telefonen trykker du **✉ Send til mail**. Første gang skriver du modtageradressen under **✉ Mail**. Adressen gemmes kun på telefonen.
2. Mailen indeholder kladden som læsbar tekst og et dataafsnit.
3. På PC'en åbner du **Journalflow (lokal)** → **📥 Indlæs fra mail** og indsætter hele mailen. Kladden fordeles felt for felt.

## Data

Alt, hvad der skrives, gemmes kun i browseren på den enhed, du bruger. Intet gemmes i dette repo.
