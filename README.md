# Akut-Flow

Arbejdsværktøjer til Alb Akut- og Traumecenter i to udgaver: web og lokal fil til PC. Mobiludgaven (`mobil/`) er parkeret og opdateres ikke mere.

**[Åbn Akut-Flow](https://alangeland.github.io/Akut-Flow/)**

## Udgaver

| Udgave | Hvor | Til |
|---|---|---|
| **Web** | `index.html`, `ghostwriter.html`, `fieldnotes.html`, `specialefordelingshatten.html`, `vagtflows.html` | Åbnes direkte i browseren via GitHub Pages. |
| **Lokal** | `lokal/Ghostwriter-lokal.html`, `lokal/Fieldnotes-lokal.html`, `lokal/Specialefordelingshatten-lokal.html`, `lokal/Vagtflows-lokal.html` | Hentes og åbnes som fil i Edge/Chrome på PC'en. |

## Værktøjer

- **Ghostwriter** (tidligere Pasteplaner og Journalflow): journalkladde som klikjournalen med fraser, normalfund og planer, der fordeles i journalfelterne.
- **Fieldnotes:** hurtige vagtnoter med zone, stue, afdeling og 5 prioriteter, færdig-markering og overleveringstekst.
- **Specialefordelingshatten** (tidligere Fordelingshatten): ASA – optælling pr. speciale i zonerne, bedste fordeling af nye akutte og 💾 Gem fordeling til loggen.
- **Flows:** samler to editorer med en vælger øverst – **Tidslinjer** (`vagtflows.html`, tidligere Vagtflows: faser og trin for vagtfunktioner, fx ASA-vagten, print som PDF i A4/A5) og **Flowcharts** (`flowcharts.html`: beslutningsdiagrammer med flere ben, print som PDF, PNG eller SVG).

## Opdatering

- **Web** opdateres automatisk, når der er pushet en ny version.
- **Lokal:** hent filen igen fra startsiden eller fra mappen `lokal/` (Raw → Gem som). Planer, normalfund og kladde ligger i browseren og bliver liggende.

## Data

Alt, hvad der skrives, gemmes kun i browseren på den enhed, du bruger. Intet gemmes i dette repo.
