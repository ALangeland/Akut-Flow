# Akut-Flow

Samlede arbejdsværktøjer til Alb Akut- og Traumecenter – én app, der kan installeres på telefonen og virker uden net.

**[Åbn Akut-Flow](https://alangeland.github.io/Akut-Flow/)**

| Værktøj | Fil | Formål |
|---|---|---|
| Journalflow | [journalflow.html](journalflow.html) | Journalkladde som klikjournalen med fraser, normalfund og planer (bygger på Pasteplaner). Hele kladden kan sendes til en mailadresse, du selv skriver ind i appen. |
| Fordelingshatten | [fordelingshatten.html](fordelingshatten.html) | Optælling pr. speciale i ASA-zonerne og jævn fordeling af nye akutte. |
| Noteflow | – | Kommer i næste version. |

## Installér på telefonen

- **iPhone (Safari):** åbn linket → Del → **Føj til hjemmeskærm**.
- **Android (Chrome):** åbn linket → **⇩ Installér** øverst, eller menuen ⋮ → **Installer app**.

## Data

- Alt, hvad der skrives, gemmes kun i browseren på den enhed, du bruger. Intet gemmes i dette repo.
- Mailadressen til Journalflow skrives ind under **✉ Mail** i appen og gemmes kun på enheden.
- Mail sendes gennem enhedens egen mail-app.

## Filer

- `index.html` – startside med versionshistorik og installationsvejledning
- `manifest.webmanifest`, `sw.js`, `icons/` – gør siden installerbar og offline
