# Akut-Flow

Arbejdsværktøjer til Alb Akut- og Traumecenter i tre udgaver: web, mobil og lokal fil til PC.

**[Åbn Akut-Flow](https://alangeland.github.io/Akut-Flow/)** · **[Mobil](https://alangeland.github.io/Akut-Flow/mobil/)**

## Udgaver

| Udgave | Hvor | Til |
|---|---|---|
| **Web** | `index.html`, `ghostwriter.html`, `fieldnotes.html`, `fordelingshatten.html`, `vagtflows.html` | Åbnes direkte i browseren via GitHub Pages. |
| **Mobil** | `mobil/` | Installeres på telefonen og virker offline. Ghostwriter kan sende kladden på mail. |
| **Lokal** | `lokal/Ghostwriter-lokal.html`, `lokal/Fieldnotes-lokal.html`, `lokal/Fordelingshatten-lokal.html`, `lokal/Vagtflows-lokal.html`, `lokal/ASA-Flow-lokal.html` | Hentes og åbnes som fil i Edge/Chrome på PC'en. Kun den lokale Ghostwriter kan indlæse kladder fra mail (📥 Indlæs fra mail). |

## Værktøjer

- **Ghostwriter** (tidligere Pasteplaner og Journalflow): journalkladde som klikjournalen med fraser, normalfund og planer, der fordeles i journalfelterne.
- **Fieldnotes:** hurtige vagtnoter med zone, stue, afdeling og 5 prioriteter, færdig-markering og overleveringstekst.
- **Fordelingshatten:** optælling pr. speciale i ASA-zonerne, bedste fordeling af nye akutte og 💾 Gem fordeling til loggen.
- **Vagtflows** (tidligere Vagtflow): tidslinjer for vagtfunktioner, fx ASA-vagten – faser og trin, print som PDF i A4/A5.

## Opdatering

- **Web og mobil** opdateres automatisk, når der er pushet en ny version. Mobilappen henter den næste gang, den åbnes med net.
- **Lokal:** hent filen igen fra startsiden eller fra mappen `lokal/` (Raw → Gem som). Planer, normalfund og kladde ligger i browseren og bliver liggende.

## Installér på telefonen

Åbn mobil-linket:

- **iPhone (Safari):** Del → **Føj til hjemmeskærm**.
- **Android (Chrome):** **⇩ Installér**, eller ⋮ → **Installer app**.

## Mail fra mobil til lokal

1. På telefonen trykker du **📎 Send**. Del-menuen åbner – vælg Mail. Kladden er vedhæftet som fil, og din modtageradresse (skrives under **✉ Send / mail**, gemmes kun på telefonen) er kopieret, så du kan sætte den ind i Til. Vil du hellere have teksten direkte i mailen, så brug **✉ Send som tekst** samme sted.
2. Filen og mailen indeholder kladden som læsbar tekst og et dataafsnit.
3. På PC'en kopierer du hele mailen (Ctrl+A, Ctrl+C), åbner **Ghostwriter (lokal)** og trykker **Ctrl+V** – eller bruger knappen **📥 Fra mail**. Den vedhæftede fil kan du trække direkte ind i Ghostwriter eller åbne med **📂 Indlæs fil**. Kladden fordeles felt for felt.
